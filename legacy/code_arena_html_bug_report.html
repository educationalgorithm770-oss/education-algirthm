Code Arena HTML Sandbox & Worker Bugs Guide

HTML5 Preview Mechanism, Playwright Web Worker Bug (BUG-008) & Solution Guide

🖥️ How Code Arena Handles HTML5 / CSS3 / JS Web Preview

Inside code-view.php, when a student submits HTML/CSS/JS code, Code Arena runs a dual preview mechanism:

  1. Client-Side Live Preview: Injects student code into an isolated <iframe srcdoc="..."> element with a custom console.log() interceptor script that forwards terminal logs using window.parent.postMessage().
  2. Backend Automated Web Runner: Sends student HTML code to code-arena/workers/WebRunner.php to run automated DOM validation assertions using Headless Node.js.

⚠️ BUG-008: Missing Playwright Dependency in Web Worker

Problem Description

When WebRunner.php triggers backend headless testing via node playwright-runner.js, Node throws an unhandled exception:

Error: Cannot find module 'playwright' Require stack: - c:\xampp\htdocs\project3\code-arena\workers\playwright-runner.js

What Issues Will You Face?

Automated grading for HTML/CSS web development challenges will fail with status WEB_RUNNER_UNAVAILABLE. (Note: Client-side iframe live rendering in code-view.php continues to function normally).

How to Fix BUG-008

Open Terminal / Command Prompt and run NPM install inside code-arena/workers/:

cd c:\xampp\htdocs\project3\code-arena\workers npm install playwright

⚡ Code Arena Local Fallback Bugs (BUG-002 & BUG-006) Summary

BUG-002: Multi-line Loop AST Parsing Loss

When Docker (port 8088) is offline, NativeWorker.php evaluates Python/Java/C++ line-by-line via regex. Loops return initial uncomputed values (e.g. Total: 0 instead of 15).

BUG-006: String Addition Concatenation in Print Statements

Parenthetical math expressions like System.out.println("Total: " + (x + y)) evaluate (x + y) as string concatenation "100" + "250" => Total: 100250 instead of 350.

Recommended Solution

Launch start_runner.bat in project root to start the 24/7 Docker Code Runner microservice on port 8088.
