BUG-003 Explanation & Solution Guide

Inconsistent File Extension Links in Static HTML Templates • Workspace: c:\xampp\htdocs\project3

🔍 What is BUG-003?

In your static template files (about.html, courses.html, contact.html, index.html), header and footer navigation links contain explicit .html and .php extensions in anchor href tags (e.g. href="courses.html" or href="login.php").

Meanwhile, your .htaccess routing rules are configured for clean, extensionless URLs (e.g. http://localhost/project3/courses).

⚠️ What Issues Will You Face If Not Fixed?

1. SEO Duplicate Content Penalty (Canonical URL Mismatch)

Search engines like Google index both /courses and /courses.html as two separate pages with identical content, causing duplicate content penalties that lower search rankings.

2. Inconsistent Navigation Experience for Students

When students click top navigation links, the URL bar jumps back and forth between clean routes (/courses) and file extension routes (/courses.html), creating an unpolished brand experience.

3. Broken Links When Migrating to PHP Routing

If you convert courses.html into dynamic courses.php in the future, links pointing explicitly to href="courses.html" will throw HTTP 404 Not Found errors.

🛠️ How to Fix It (Code Diff)

Open about.html, courses.html, contact.html, and index.html. Replace all explicit file extensions in href attributes with clean extensionless routes:

- <a href="courses.html" class="nav-link">Courses</a> + <a href="courses" class="nav-link">Courses</a> - <a href="contact.html" class="nav-link">Admissions</a> + <a href="contact" class="nav-link">Admissions</a> - <a href="login.php" class="btn btn-secondary">Student LMS</a> + <a href="login" class="btn btn-secondary">Student LMS</a>
